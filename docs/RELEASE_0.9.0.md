# 0.9.0：输入中断修复与试玩评测基础

日期：2026-11-23。内容目录仍为residential-5，出题器仍为0.8.0；本版不重排关卡、不重建回退库，也不改变审核和星级。

## 玩家侧修复

- 输入状态跨界面重绘保留触点生命周期。双指缩放后先松一指，剩余手指不得落笔；必须全部抬起再开始新笔画。
- 旋屏、画布尺寸变化、后台切换、窗口失焦、pointercancel及意外lostpointercapture统一取消尚未提交的预览；不会把中断当作完成。
- 拖画、擦除、门窗、家具拖放和平移都绑定开始的pointerId，其他指针抬起不能提交它。
- 界面控件和需求滚动上的触点不参与地图双指缩放。
- 求助推进教学后提示保留实际补画的房间名称，避免补画走廊却显示卧室。

事件语义依据[MDN pointercancel](https://developer.mozilla.org/en-US/docs/Web/API/Element/pointercancel_event)与[lostpointercapture](https://developer.mozilla.org/en-US/docs/Web/API/Element/lostpointercapture_event)。正常释放捕获不等于异常；判断仍以活跃触点/拖动是否存在为准。

## 本地观察与独立后台

玩家界面不增加评测入口。汇总存放当前浏览器的paper-studio:playtest:v1，最多200份委托、100次出题；不记录图纸或触点坐标，不上传。仅在进入游戏后创建观察记录，停在首页不计作一次试玩。

记录有效活动用时、修改、撤销/重做、求助、失败提交、输入中断与首次通过。后台、游戏菜单/设置/帮助等弹窗暂停；60秒无输入后停止累计，持续拖动和滚动仍算活动。重载不把离线时间计入；首次通过后冻结，不改变原有星级。

旧草稿从中途观察开始，不补造过去用时、失败或求助；仅“从开始观察且已通过”的样本用于完整通关用时中位数。不同轮次独立。自动记录不包含真人难度评分或用途合理性意见。

独立本地页面/admin/playtests.html读取同源记录，可下载汇总JSON；随dist/admin整体排除出Pages。手机局域网IP、localhost和线上地址的浏览器存储彼此独立，本地后台不能直接读取手机或线上浏览器的数据。尚无服务器汇总和远程采集。

出题测量分别记Worker、回退及总等待；总等待含校验/下载。观测回调和存储失败均不能中断出题或游戏。

## 自动评测与验证范围

运行`npm run benchmark:quality -- /绝对路径/report.json`。54个固定请求覆盖阶段引入/复用、12类结构，以及第1000/10000份委托；连续传入近期结构和指纹。每份校验格式、全部要求、参考解、用途通行和60项/12类预算，输出耗时、相似限制及错误。第1000/10000份能生成不代表无限种内容或无限递增难度。

2026-11-23 Apple M4 / arm64 / Node24.11.1：54/54通过，生成失败0、无效参考解0、相似限制0，计算P50约143ms、P95约199ms、最大约243ms。这是顺序Node计算，包括生成器内部验证；不含浏览器Worker启动、网络和手机硬件，不能用来验收手机P95。

127项自动检查通过。隔离浏览器用实际app.js和DOM事件验证双指/取消/捕获丢失/重绘/陌生pointerup/视口换向均不提交，新笔画仍可画9㎡；合成事件夹具替换了原生指针捕获，不代表真机触控。另经真实界面按钮完成3次求助、审核0星与领取第2份委托，确认本地记录出现完整样本和Worker计时；此为QA样本，不能纳入真人难度校准。

验收步骤和采样口径见[真机与难度验收](PLAYTEST_PROTOCOL.md)。
