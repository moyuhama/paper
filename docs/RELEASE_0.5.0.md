# 0.5.0 关卡质量与教学

本版改进新委托的线索和户型筛选，并为新增内容补教学。家具仍为21类，结构目录仍为12种；旧草稿、历史提交和成绩沿用保存的题目。

## 有效方位线索

第12关起，出题时为每件参考家具尝试最多4种替代占地。替代布局必须保持房间归属、家具数量、门窗和其他家具不变，并通过碰撞、固定结构与通路检查。

候选方位条件根据能排除哪些替代布局筛选。按阶段预算选取后，再移除被其他已选条件完全替代的条件。每条最终方位条件都保留至少一个独立反例：该布局通过基础要求和其他已选方位条件，却违反这一条。因此不再用“后期至少12条方位条件”作为质量标准。

这些证据只覆盖参考分区内的局部家具摆位，不覆盖所有房间划分、门窗摆放和多物件联合移动，不证明唯一解，也不保证全局没有冗余。每份新题保存抽样数量、排除数量和每条线索的独立反例数；这些信息不进入玩家页面。

99份回退快照重建后，第12～17关平均保留5条有效方位条件，抽样排除比例平均61%；第30～35关为10条和94%；第42～100关为11.34条和97%。这是生成器的抽样指标，不能代替人的解题时间与难度评价。当前仍是6阶段预算，尚未实现无限递增难度。

## 相似户型筛选

在完整题目指纹之外，增加忽略家具、条件、标题和种子的结构描述。整体平移、旋转、镜像不会使同一分区变成新结构；近似比较使用房间面积比例、房间中心相对距离、相邻关系与外框比例。

普通新题优先避开最近两题的结构族，并对最近五题的结构相似度筛选候选。首次引入某种结构的教学关仍保留既定类型。计算预算内找不到足够不同的候选时可返回已验证的最佳候选，并记录筛选受限；不以外观相似为由丢弃当前图纸或无限等待。

Worker接收同轮近期结构；无Worker和超时回退也优先换结构族。回退仍为小索引加单题按需下载，不下载整库，不保证全球唯一或永不重复。

## 内容教学

- 家具首次解锁时显示该物件的占地和摆放要点，涵盖现有全部家具。第一关保留原有分步绘图教学。
- 首次遇到已支持结构时说明可用面积、通路或固定结构限制，包含斜角半格、柱位、管井、固定墙和天井的区别。
- 提示位于独立浮层，可逐条阅读、收起和从游戏菜单重开；阅读记录随存档保存，新一轮游戏重新学习。
- 设置关闭教学时不自动弹出，手动重开仍有效。单题无关家具不出现在教学或物件带中。
- 手机提示关闭按钮44×44，常驻底栏仍52px，需求仍默认展开且在地图下层。

## 验证与后续

93项自动检查覆盖原有规则、生成、音量、评分、历史与相机，以及有效线索独立反例、结构等价、连续结构族选择、教学目录和无Worker回退。第12～100关、各结构8组种子和99份回退参考解继续通过共享判定。

隔离测试页使用生成器参考布局，实际完成第30关60/60审核并领取第31关；工作台教学可推进、收起和重开，第31关固定墙及第33关斜角说明正确。390×844竖屏和844×390横屏未出现整页横向溢出；旧本地第一关9㎡卫生间草稿保留。参考布局验收不代表人工解完全部关卡，尺寸模拟不代表真机触控验收。

下一步保留为独立验收项：真机多指操作与性能、实玩难度校准、多实例自动组合、正面使用区与近邻规则；再推进第二批家具。任意角多边形和后台内容流程仍按原路线后续实施。
