# 0.10.1：限制提交资格与重复提交

用户指出提交方案可以无限点击。本版按用户要求修复：只有全部条件与结构校验通过、且本次委托尚未审核通过，才可提交。

此前按钮没有disabled状态，提交函数也没有完成/已通过校验，因此空图能反复追加失败记录，通过后也能继续追加成功版本。现在按钮和动作入口共用submissionStatus；submitDesign在写入评分、聊天、历史和评测之前重新校验，不符合资格的点击不产生任何审核记录或扣分。

通过后按钮显示“已审核通过”并禁用，只保留领取下一份的流程。同一份委托通过后，即使再修改或撤销当前稿，也不能重复提交；仍可以领取下一份，已审核的历史图纸与成绩保留。领取新委托后，按新图纸的完成状态重新开放提交。

旧失败/求助扣分和历史审核记录保留，不删除或重新评分。旧存档存在先通过、后又重复失败的记录时，仍识别曾经通过，可以继续领取任务。评分算法和关卡生成不改；本次未完成拒绝属于用户明确要求的玩家交互修订，不冒称原作没有失败评分。

138项检查通过，新增覆盖空白/缺条件/碰撞、连续重复提交、通过后改稿、旧成功记录和原有扣分保留。隔离浏览器真实界面验证：未完成按钮禁用，重放3次提交无记录；完成参考稿后正常提交三星；通过后重放5次仍只有v1；改为空图后仍能领取第2份，第2份未完成时提交再次禁用。参考稿仅为测试夹具，不代表人工解题。
