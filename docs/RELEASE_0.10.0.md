# 0.10.0：轮次出题与备用题可用性

日期：2026-11-23。生成器0.10.0，内容目录仍residential-5；没有新增家具或几何规则。

## 修复的问题

此前正常出题的随机流只取委托编号及候选序号。开始新游戏虽建立了独立聊天/成绩轮次，生成器没有收到这个轮次，因此相同进度会重走相同题目序列。修复前抽查12、18、30、38、46、50、62、64、66、67、80、100共12个阶段，两轮的题目指纹全部相同。

现在玩家领取下一份委托时，把已保存的campaignId作为variationSeed传入客户端和Worker。第12份起参与模板选择、空间尺寸、用途组合、家具摆放和线索抽取的随机流；相同轮次、阶段与近期上下文仍可复现。前11份基础教学保持原布局流，家具/结构首次引入仍按阶段进行。

使用独立、稳定、有界的轮次键，不在生成器调用Math.random。原始轮次不作为游戏显示的种子；玩家仍看到委托标题，页面不增加开发入口。未提供轮次的工具/固定样本保留原随机流。旧关卡快照、图纸、星级、撤销与聊天仍按原数据恢复，不用新生成器重算旧题。

客户端核对Worker返回的轮次键，避免旧Worker忽略轮次却被当作新变体接收；不符时进入已验题回退。

## 回退规则

无Worker或出题超时仍用现有99份、按需下载的已验快照。第2～66份精确匹配阶段，保持首次教学；这些快照没有因为换轮次就变成新题。后期候选按轮次与阶段稳定排序，同时优先避开近期结构族、排除已提供的近期指纹。

单个快照下载失败时，可以继续尝试后面的候选；最多尝试3份，下载阶段总预算10秒，每次最多5秒，保持有限等待。格式/内容版本/解锁/新机制/参考解仍必须复验。全部失败会保留当前稿并提示重试，不接收坏题。

本版复用原0.8.0生成的99份已验快照：目录内容版本相同，兼容规则没有变化，完整测试复验通过；不靠改旧快照伪造内容扩充。缓存是有限保障，不承诺无限不同题目。
