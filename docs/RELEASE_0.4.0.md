# 0.4.0 实现与验收

2026-11-22。本次为实际代码实现，早期规划中的后续候选不全部包含在本版本中。

## 已实现

- 家具目录从11类扩为21类，集中配置占地、名称和解锁阶段；房间采用核心家具、可选家具及卫浴替代组合，按实际参考解验证空间与通路。
- 第12/14/16/18/20/22/24/26/28/30关分别引入冰箱、茶几、电视柜、床头柜、书桌、书柜、洗手台、洗衣机、鞋柜、工作台。新物件进入需求、参考解、方位条件、物件列表和任务手机提示。
- 新增书房、家政间、储物间、工作室等用途配置。单题最多12类家具，保持一条铅笔物件带，手机按需展开。
- 进阶结构目录含双区、L形、缺角、狭长入口、U形、凸出阳台、柱位、管井、固定墙、斜切角、天井和错位双翼12种配置。它们包含外轮廓和内部固定结构变化，并非12种完全不同的外轮廓。
- 第13/15/17/21/23/25/27/31/33/35/37关分别引入上述进阶变化，其他题从阶段已开放结构中选择。
- 固定柱/井不可占用，固定墙不可拆改或被家具跨越；天井可以按题目开窗，不能被当成额外入户口。区域外部由连通分类识别。
- 几何版本2支持45°斜切角：保存真实半格三角形、计算多边形面积，按实际斜墙段放门窗；整格家具不能侵入半格。绘图、预览、审核、求助、撤销、历史图和后台预览共用数据。旧格式继续读取。
- 第12关起按6阶段增加方向/负向条件预算，常规题最多60项需求；去掉对称重复的开放连接条件及部分冗余线索。
- 题目指纹忽略编号、标题、种子和整体旋转/镜像；同一轮游戏的近期重复题会更换候选。此为重复筛选，不是全球唯一性保证。
- 出题在Worker执行，限时后使用99份预验证快照中的匹配阶段题，保留本关新物件/结构；失败不覆盖当前图纸。回退题库不是总关数上限，正常出题仍按委托编号持续生成。
- 手机复杂户型初始比例至少65%，仍可手动缩小查看全图或放大操作。52px底栏、左侧滚动条、图层关系和独立后台保持。

## 验证

- 86项自动测试，含原有编辑/评分/历史/音量/手机相机回归。
- 第12～100关参考解、每种结构8组种子、现有150个固定种子、99份回退快照通过共享判定。新解锁物件不能缺失，单题家具和线索预算受检。
- 正反例覆盖固定墙、管井/柱位、天井、半格面积/碰撞、斜墙门窗、旋转等价指纹、Worker正常/超时/错误/不可用和回退失败。
- 独立本地测试实例中，第33关斜切角设计稿实际审核为3星，领取第34关成功；旧斜边历史图关闭后，第34关空白草稿保持。
- 实际点击斜窗改为门，入户门由1/1变为2/1、窗由23/23变为22/23，撤销后60/60恢复；工作台可选择及转向90°。
- 手机尺寸390×844、844×390核对：整页不横向溢出、底栏52px、滚动条在左、选物件后列表收起、转向按钮不越界。该检查不替代真机多指触控验收。

旧草稿使用保存时的题目，领取新委托才采用新生成器。没有自动清空或重写玩家已有成绩。
