## 房间与空间规则

新增琴房、健身房用途，并复用游戏室；引入关强制使用对应房间，之后按阶段加入普通用途池。它们与走廊连接，按私密房间检查，不能被参考布局当作穿行交通。第58关起为可能出现家政柜的小家政间增加空间预算，柜体、洗衣机、门口与操作侧共同验证。

餐桌/吧台、普通书桌/转角书桌、床头柜/梳妆台、鞋柜/玄关长凳、家政柜/晾衣架是替代组合，不永久累加全部已解锁物件。单题家具种类上限仍为12；第12关起的常规题最多60项可见要求。增加正面要求时，按剩余线索容量选择有效方位条件，保留明确使用区与通行要求。

7类有正面定义的新品种在出题时实际预留1m使用区，并以可见条件列出。使用区随朝向变化，必须空置、位于同一房间、无固定墙阻隔且可从入口走到。转角书桌的空缺不是家具碰撞占地，但可属于要求留空的工作区。晾衣架和游戏桌沿用占地、方位、数量、距离及可达使用位置等条件。
