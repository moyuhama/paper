# 0.10.3：进入游戏动画

开始游戏、开始新游戏和继续游戏接入同一段入场：标题页约150ms淡出，图纸轻微上移/展开，工具栏及桌面手机依次进入；有任务手机时延后300ms开始呈现。正常总时长约0.6～0.8秒，普通编辑、切换工具和领取下一份委托不重播。

入场使用浏览器原生Web Animations，只动画opacity/transform；结束后取消临时效果，保留原有手机旋转、图纸比例和视口。实现参考[Element.animate](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)与[Animation.finished](https://developer.mozilla.org/en-US/docs/Web/API/Animation/finished)。

动画期间root inert/输入锁和动作入口共同阻止重复开始、键盘快捷键及绘图误操作。开始新游戏的数据初始化只执行一次，继续游戏保留草稿；该时段不纳入有效解题计时。减少动态效果偏好直接进入；窗口尺寸变化、进入后台或动态效果偏好变化会结束移动，解除锁。动画API不可用、取消、等待超限或进入回调异常均有清理路径，避免停在不可操作画面。

143项检查通过。隔离浏览器以真实原生动画验证离场/入场两个阶段，连续触发5次只执行一次初始化，正常约772ms；减少动态效果夹具创建0段动画、约20ms恢复可操作。手机尺寸390×844→844×390于动画中切换时约247ms结束，页面宽度844、无横向溢出且可操作。此为浏览器尺寸与偏好模拟，不等同于物理手机性能/触控验收。截图为动画结束态，截图接口会稳定动态效果，不作为逐帧时长证据。
