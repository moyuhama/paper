# 0.7.0 指定家具标记与L形沙发

本版完成玩家可操作的A/B家具标记，并加入第二批家具中的L形沙发。当前家具总数22类，结构目录仍为12种；31类候选尚未全部实现。

## 第46份委托引入指定家具

同类重复家具获得A、B标记，标记同时显示在图上和对应条件中。新放家具自动获得该房间、该类型尚未使用的标记，也可手动指定或不标记；数量要求会明确列出需要的A、B。

用抓手选中家具，再点底栏的标记按钮，可交换A/B，家具的位置和内部身份不变。移动、转向、撤销、补画、存档与历史图保留标记。未放下的新家具不能抢占已使用的标记；交换已有标记通过选中家具操作完成。

条件通过逻辑标记选择来源或目标，不要求玩家复用参考解内部ID。缺失、重复、错误类型或未定义的标记不能通过；旧关卡没有标记要求时不会被追加条件。新题保留至少一条有实际作用的标记条件，第一份标记教学题的参考布局交换A/B后会违反对应条件。参考布局仍不是唯一合法解。

## 第48份委托引入L形沙发

L形沙发外框3×2格，实占4格；缺口不属于家具。四向旋转、碰撞、放入房间、擦除、预览、选中轮廓、固定墙检查与通路计算共用真实占格，不能用实心矩形冒充L形。

正面使用区随实际形状和方向变化，L形内凹部分即使不是家具占地，也可能属于题目要求留空的使用区。方向条带按每行/列的实际占格边缘延伸；距离和连线按实占单元的真实边缘计算，不能把缺口内外框重叠误算为家具接触。原有矩形家具的条带与距离判定保持。

新沙发替换部分后期起居组合，不永久叠加全部已解锁家具。它进入需求、参考解、方位条件、铅笔统一列表和专属教学；同题可与A/B标记、多件数量、正面使用区和距离规则组合。当前只有一种L形占地及四向旋转，左右款与其他异形家具继续逐种扩充。

## 生成、回退与界面

- 内容版本residential-4，生成器0.7.0；99份独立回退快照重建，索引加单题按需下载保持。
- Worker和回退都校验解锁家具、首次引入家具和机制，不能在第48关返回缺少L形沙发的旧题。
- 标记的对应关系进入题目指纹；结构相似筛选仍忽略家具与条件。局部线索检查继续保留合法摆位反例，不宣称完整解空间或唯一性证明。
- 玩家没有增加开发面板或分类页。手机只在相关家具选中或待放时显示44px标记按钮，常驻底栏仍52px；抓手的物件列表仍为空。
- 第一关仍由代码定义，服务端关卡数据库和后台内容发布流程没有在本版新增。

## 验证

112项自动测试通过。新增覆盖A/B交换与选择器、自动分配、缺失/重复/错误标记、四向L形占地、缺口碰撞与擦除、真实边缘距离、实际条带、参考解/教学/历史与新内容回退。旧0.6第46题快照仍通过原要求，重新计算的语义指纹与保存值一致。既有第12～100题、结构种子和99份回退题继续验过。

隔离浏览器验收使用生成器参考布局：第46题交换两张床的A/B，四条对应条件即时失效，撤销后恢复。第49题移动L形沙发B、180°转向270°，B身份保持；两步撤销后恢复。参考稿60/60审核通过并领取第50题；历史图保留A/B和L形轮廓，关闭后第50题草稿仍为空白。

320×568手机尺寸下，标记按钮44px、底栏52px，待放物件/标记/转向均位于屏幕内，无整页横向溢出；标记弹框可见可操作。该尺寸检查不替代真机多指触控和性能验收。
