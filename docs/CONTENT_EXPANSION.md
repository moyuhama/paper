# 道具、房间与关卡持续扩展方案

状态：待实施规划，2026-11-22。当前线上仍为11类家具。下文新增道具、章节、新规则和指标均未实现，不作为上线说明。

## 产品目标

现有11类只是第一批基础内容，不是产品上限。持续游戏需要同时建设内容库、生成器和难度进程：内容包带来新的物件和用途，生成器组合出题，难度进程安排学习和挑战。自动生成不等于自动创造新道具。

首批扩充到21类，准备扩至31类的后续候选；以后继续增加内容包，不将31设成最终上限。新增部分为本项目原创设计，不声称原作已有这些物件或规则。占格尺寸是待试玩的游戏参数，不作为建筑或家具尺寸标准。

每种新道具须有用途、可辨认的俯视图、占地与朝向、适用房间、可以形成的布局问题和通过验证的参考解。同功能同规则的外观变体归为皮肤，不用皮肤数代替内容增长。

玩家端仍是一条铅笔物件列表。本文用途分组只服务内容制作和后台，不新增玩家分类切换；后台和游戏保持独立。

户型轮廓同样属于主线内容，详见[非规则户型扩展](FLOORPLAN_EXPANSION.md)。先支持缺角、L/U等正交结构和固定建筑障碍，真正斜墙、多边形面积与碰撞作为后续几何升级；不能仅增加家具或反复使用矩形拼接模板。

每次引入后至少安排一关复用。引入关必须选能容纳新物件的用途和模板，任务手机说明新增内容；下一关巩固，再与其他关系组合。新物件与新的硬性判定规则不在同一关首次引入。

解锁以首次通过对应委托为准，不要求三星；求助通关和低星通关仍可继续。重玩、撤销或查看旧图不会重复解锁或回收新物件。新增内容依赖具体功能和教学前置，不只检查一个章节数字。

第12～30关是首个扩展包安排，不是最终终点。未制作、未验证的物件不能提前标为已解锁。解锁目录增长不代表每题都塞入全部旧物件。

## 门窗和其他道具的扩展

家具之外，另行规划宽门、推拉门、连排窗等结构物件。这些涉及连续多段墙边、长度和数量单位、开口与通行关系，不能按普通家具放在房间格子里，也不能简单把两段边界统计成两扇门。需先定义一个结构实例跨哪些边、能否旋转、哪侧房间连通以及相应需求文本，再做生成和教学。31类目标仅计算家具，不把门窗变体混入数量凑目标。

地毯、墙饰、桌面摆件等候选涉及地面/墙面/台面分层及允许重叠；当前引擎没有这套放置层。后续如引入，先补放置层和玩法价值。纯装饰作为可选外观内容，不强制加入每题的审核条件。

## 难度、解锁和单关内容分开管理

总体挑战逐步提高，同时安排巩固关。单关不强制比前一关更大、更长或使用更多物件。

| 阶段 | 内容重点 | 推理重点 |
| --- | --- | --- |
| 第1～11关 | 现有基础家具和教学 | 绘制、门窗、旋转、方向、通行；保留已保存旧题 |
| 第12～20关 | 首批前5种、客厅/厨房/卧室/书房变体 | 每次限制新知识点，2～3房间依赖 |
| 第21～30关 | 书柜、洗手台、洗衣机、鞋柜、工作台 | 家具组合、用途分区、公共/私密空间与通路 |
| 后续进阶包 | 第二批候选逐项验收后加入 | 多件、替代、正面使用和异形分别教学 |
| 持续委托 | 已解锁且支持的内容包组合 | 结构族、线索和主题变化，难度受设备和可读性约束 |

常规题同时出现物件种类暂以8～12类为目标，精选复杂题另行评测。目录达到31类时也不一次展示31类。常规题暂以不超过60条可见条件为目标，超出时先删除重复线索或拆关。这些是待校准的设计目标，尚无体验验收结论。

难度指标包含：房间用途组合、家具占用比例、可行候选摆位、跨房依赖链、多个条件共享物件的程度、正负条件冲突及旋转/异形几何。房间数和条件数仅为辅助。当前尚无解空间评估，须用受限搜索和试玩校准，不宣称唯一解或精准难度。

## 数据和版本设计

下一版将解锁表扩为内容目录，至少包含稳定ID、名称、内容包版本、解锁阶段/前置内容、俯视图、四向朝向、碰撞占格、使用区、功能标签、适用房间、组合配置、数量范围、支持的条件、说明与验收样例。使用区不能混为碰撞占格。

房间组合独立配置，例如“淋浴+马桶+洗手台”和“浴缸+马桶+洗手台”，不能给卫生间永久累加所有已解锁设备。明确必需、可选和互斥物件，先满足空间预算，再出题。

同类多件拥有独立实例ID。来源选择器明确区分每张床、任意一张床、指定床；条件文本和判定一致，不能用第一件的结果代替全部物件。新规则必须有独立教学、正反例及生成支持。

每个新题保存内容包版本、生成器版本、规则版本、解锁快照和完整题目快照。新版本不向旧草稿补要求，不改变旧提交和星级；领取新题时再采用新内容。旧ID不改义。

## 生成质量和失败处理

1. 根据阶段选内容包、主题、新物件和线索预算。
2. 选房间用途与家具组合，预算碰撞面积、门口和使用区，再选合适结构。
3. 构造分区及门窗，优先摆大件/有使用区的物件，再摆小件，每一步验证通路。
4. 从实际参考布局提取受支持条件，筛选有效线索，不把全部可成立事实列给玩家。
5. 用玩家同一引擎复验，确认新物件出现在需求、参考解、物件带及相关关系中。
6. 生成语义指纹去重，忽略编号、标题和种子文本，考虑整体旋转/镜像，避免反复翻转同一题。
7. 评估难度和生成预算，保存配置；仍接受偏离参考布局的合法解。
8. 超预算时限次换组合或模板；最终回退到同阶段、仍包含必需新物件的已验题，不能卡死或漏掉本关新物件。

复杂生成移入Worker，避免阻塞手机。待测初始目标：桌面P95小于250ms、目标手机P95小于800ms、单次总预算1.5秒；记录测试设备并按结果调整。当前尚无这些实测，也未完成Worker、限时生成与回退。

## 界面和内容制作

任务手机说明新道具用途与基本摆法；提示可收起、重开。铅笔带只列本题相关道具，仍为同一列表；手机保持按需展开、选后收起，抓手为空。

选中时显示占地和朝向预览；以后有指定使用区的物件再显示相应轻量预览。只有关卡明确列出的规则才能扣分或阻止通关。非法放置应说明具体原因。

目录编辑、生成配置、素材制作、导入导出和出题验证留在后台，不搬进玩家界面。新增图形保持既有手绘纸面和俯视SVG风格。
