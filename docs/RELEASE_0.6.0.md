# 0.6.0 多件家具与空间规则

本版落实多实例自动出题、量词教学、显式正面使用区和家具距离条件。家具仍为21类，结构目录仍为12种；第二批31类候选和一般多边形未包含在本版。

## 判定与操作

每件参考家具拥有独立ID，同一房间同类家具共用一条数量要求。铅笔列表仍只列一次该家具，连续放置即可；玩家每次放置拥有独立ID，可以单独移动、转向、擦除、撤销。逐房补画与历史图保留所有实例。

“每个”要求所有匹配来源都满足，“至少一个”要求至少一个来源满足；缺少来源不能真空通过。距离使用每件来源到最近匹配目标的距离，同类目标排除自己。内部objectId选择器继续支持判定，但本版没有玩家命名特定实例的交互，不能把内部ID支持当作“指定某一张床”玩法已经交付。

正面由图上的绿色箭头表示，随四向旋转变化；180度转向即使占地不变也会改变使用区。要求中的整排空地必须在同一房间内、无家具、无斜角半格、无阻隔固定墙，并可从入口走到。只有题目明确列出useSpace条件时才检查；正常放置仍允许暂时不满足条件，再通过需求反馈调整。目录中8类家具有正面定义，常规生成目前将此规则用于沙发，其他类型没有被自动加上隐藏要求。

距离按矩形家具边缘计算，贴边或角接触为0m；对角间距按直线计算。内部以平方距离比较，显示时才四舍五入。新题自动生成同房间、到最近目标不超过1m的条件；引擎也能读取显式距离下限，但本版常规题尚未生成下限玩法。

## 生成与界面

- 摆参考家具时同时预留正面空间；方位线索的合法替代摆位也须满足新空间条件，不能用不合法摆位证明线索有效。
- 距离条件须能排除至少一个抽样的合法家具替代摆位；这不证明整体唯一解或全局没有冗余。
- 正面朝向纳入相关题目指纹，不能把同占地、不同正面的布局当作同题。
- 新玩法分开教学，可收起、重开并保存已读状态；任务手机说明本次新内容。点击新条件可查看使用区或距离连线，预览与历史图共享正面箭头。
- 内容版本更新为residential-3，99份独立回退快照重建；Worker结果与回退都校验所需机制，不能退回缺正面或距离规则的旧阶段题。索引加单题按需下载保持。
- 修正透明地图命中层盖住需求按钮的问题：空白输入层位于要求下方，墙线与家具继续在上方可编辑。查看范围时隐藏横屏建议，避免说明被遮挡；范围关闭按钮44×44，手机底栏52px。

旧草稿仍使用保存的题目，不追加入新规则或改变成绩。第一关仍由levels.js定义，自动生成题与99份备用JSON仍按原存放方式运行；本版没有新增服务端关卡数据库。
