# 纸上事务所

在方格图纸上规划房间、门窗、开放连接和家具，完成客户委托的网页逻辑解谜游戏。

这是独立开发的浏览器版本，目前持续完善中，非《Looks Fine on Paper》官方移植。界面、图形及音频由本项目实现，不包含原作安装包、录屏或提取素材。

## 在线试玩

[打开游戏](https://moyuhama.github.io/paper/)

支持电脑和手机浏览器，手机推荐横屏。存档保存在当前浏览器中；不同设备、浏览器和网址之间不会自动同步。

## 游玩

- 从主菜单开始游戏或继续已有委托。
- 对照图纸上的需求，用铅笔选择房间、门窗和家具；物件随关卡逐步解锁。
- 拖出房间，在墙边放置门窗，在房间内放置家具；旋转按钮切换方向。
- 橡皮删除，抓手移动图纸；电脑中键拖动、手机双指支持平移缩放。
- 打开任务手机提交设计、查看审核和往期委托。求助及首次求助前的错误提交会影响星级。

包含教学关卡、参数化生成委托、约束验证、评分、历史方案、背景音乐和操作音效。生成器目前使用经过验证的户型结构族，仍需继续扩展结构和难度覆盖。

当前0.4.0有21类家具。前11类沿用教学进度，第12～30关逐步加入冰箱、茶几、电视柜、床头柜、书桌、书柜、洗手台、洗衣机、鞋柜、工作台。单题只列相关物件，最多12类。

进阶户型包含L/U形、缺角、狭长入口、阳台、错位双翼及柱位/管井/天井/固定墙。第33关起引入45°斜切角，使用真实半格面积和碰撞判定；任意角度斜墙、弧形和多层尚未支持。

第12关起分阶段增加条件组合，最多60项需求。Worker出题支持近期重复筛选、限时生成和99份按需下载的已验题快照回退；题库数量不是可玩关数上限。已有草稿及星级保留，领取新题才使用新内容。

[0.4.0实现与验收](docs/RELEASE_0.4.0.md)列出实际支持、87项测试及浏览器验证；[内容扩展方案](docs/CONTENT_EXPANSION.md)和[户型扩展方案](docs/FLOORPLAN_EXPANSION.md)保留后续候选，未实现项目有明确标记。

## 本地运行

需要 Node.js 22.16+ 或 24，无第三方运行依赖。

```sh
PORT=4189 npm start
```

打开 `http://127.0.0.1:4189/`。局域网测试可使用 `HOST=0.0.0.0 PORT=4189 npm start`，手机访问电脑的局域网地址。

关卡制作页面在本机 `/admin/index.html`，与玩家端分开；本地服务器仅允许回环地址访问后台。

## 验证和部署

```sh
npm test
npm run build:pages
```

第二条命令生成 `.pages-build/`，只包含玩家端，排除 `dist/admin/`。所有资源使用相对路径，支持 GitHub Pages 项目子路径。

推送 `main` 后，GitHub Actions 自动运行测试、打包并部署到 Pages。首次使用需将仓库 Settings → Pages 的发布来源设为 GitHub Actions。

`scripts/generate-audio.py` 用于重新生成本项目音频，属于开发工具，需要 Python、NumPy 和 FFmpeg；运行游戏及 Pages 部署不依赖这些工具。
